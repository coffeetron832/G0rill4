It is a lightweight web tool to compress your files without having to upload them to any external server. 

## Highlights

- **Extremely Versatile**: Supports common file formats such as JPG, PNG, WEBP, PDF, MP3, WAV, MP4, WEBM, SVG, JSON, CSV, and TXT (up to 100 MB).

- **100% Private and Secure**: Your files never leave your device.

- **Multiple Tabs**: Organize and process different files or formats at the same time.
